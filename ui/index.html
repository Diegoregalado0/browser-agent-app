Set up

  1. Open discord.com/developers/applications, click New Application and name it (for example Browsby).
  2. Open Bot, click Reset Token, and copy the token.
  3. Paste it below and save. Then use “Add the bot to your server” with a server of your own (a private one works), since Discord only lets you message bots you share a server with.
  4. Send the bot the pairing code shown above as a direct message.

The token stays in this Chrome profile on this computer (never synced) and is never shown again.
